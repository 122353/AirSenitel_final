# AirSentinel 3–5 minute demo video script

## 0:00–0:25 — problem

“AirSentinel addresses the gap between city-wide air-quality visibility and a local decision. A ward, village edge or industrial corridor can experience an event that a city average or a forecast misses.”

## 0:25–1:05 — working public flow

Show the public dashboard. Point to the India overview, locality evidence and forecast interval.

“These are provenance-labelled observations and historical prototype forecasts, not official AQI. The system shows one-, three- and four-hour research estimates only where the relevant evidence and evaluation gates are satisfied.”

## 1:05–1:35 — data improvement

Show the coverage table.

“Najafgarh has 7,516 saved PM2.5 hourly rows across 181.9 days with 86.1% completeness. Safdarjung has 7,889 rows with 90.4% completeness. Both have two reporting stations and all six configured pollutants. This is OpenAQ development fallback, not an authorised CPCB historical archive; it makes them candidates for a controlled conventional comparison, not operational forecasts.”

## 1:35–2:15 — sudden event

Open an unexpected-spike case.

“When reality differs sharply from the forecast, AirSentinel does not invent a cause. It creates a cause-unverified case and asks the reviewer to check station freshness, neighbouring sensors, weather, satellite/fire context and moderated citizen evidence.”

## 2:15–2:55 — citizen and authority workflow

Submit a coarse-location report, then show the authority queue and action form.

“Citizen text, photo or voice is consented, privacy-minimised and unverified. A verified reviewer chooses the next step and every action is audited. Nothing triggers automatic enforcement.”

## 2:55–3:30 — Google stack

Show the Google architecture slide or readiness endpoint.

“In the configured Google Cloud path, Firebase would handle identity and pending evidence; BigQuery would store governed analytical tables; Gemini, Maps, Earth Engine and language services have guarded adapters for reviewed context and accessibility; Cloud Run would separate a public aggregate view from private API and authority services. These account-bound services are not claimed live in this local demo.”

## 3:30–3:50 — close

“AirSentinel is a working locality-aware decision-support prototype. The remaining production steps are authorised government data, team-owned Google Cloud configuration, identity testing and a controlled authority pilot.”
