# Short project description

## Two-line version

AirSentinel is a locality-aware clean-air early-warning and human-review platform for India. It combines provenance-labelled station data, weather, satellite context and consented community evidence to forecast one to four hours ahead, detect unexpected pollution changes and guide an auditable sustainable response.

## Submission-form version

AirSentinel addresses the gap between city-wide air-quality monitoring and a local government decision. It checks six-pollutant station evidence for provenance and coverage, adds weather and contextual satellite/citizen signals, produces historical one-, three- and four-hour conventional research forecasts with uncertainty where evidence permits, and turns large forecast misses or missing coverage into cause-unverified cases for reviewer-gated human review. The prototype includes public, citizen and authority interfaces, a FastAPI backend, privacy controls and Google Cloud integration paths for Firebase, BigQuery, Gemini, Maps, Earth Engine, language services and Cloud Run. It does not claim official AQI, automated source attribution or automated enforcement.
